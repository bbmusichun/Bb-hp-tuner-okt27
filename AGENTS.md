# Agent notes

## What this project is
Resonix / "BB Tuner" — a client-only Vite + React 19 + Tailwind 4 PWA (handpan tuner).
There is no backend and no API server: `src/` is purely browser code (Web Audio API,
`localStorage`). `express`, `dotenv` and `@google/genai` are listed as dependencies but
nothing in `src/` imports them.

## Running it (Base44 / sandbox)
- `docker compose -f docker-compose.base44.yml up -d --build` — single `web` service
  (`node:22`), source bind-mounted at `/app`, `node_modules` in a named volume.
- Startup runs `npm install --no-audit --no-fund --no-package-lock`, then
  `npm run dev` (`vite --port=3000 --host=0.0.0.0`). First boot takes ~30–60s to install.
- Preview: host port 3000. Vite's host allowlist is satisfied by the platform-provided
  `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS` (`.e2b.app`), passed through by Compose; an
  unknown `Host` header correctly gets 403.
- `dev-dist/` is generated by `vite-plugin-pwa` in dev mode and is gitignored.

## Credentials
None required. `.env.example` mentions `GEMINI_API_KEY` / `APP_URL`, but no source file
reads them, so the app boots fully without any secret.

## Verification
- `npm run lint` (tsc `--noEmit`), `npm test` (`tsx --test`), `npm run build` — the same
  three steps CI runs (`.github/workflows/ci.yml`). Run them inside the container:
  `docker compose -f docker-compose.base44.yml exec -T web npm test`.
- UI smoke check: page loads with the "Hangolás" tuning view, bottom tabs
  (Hangolás / Spektrum / Hangmező / Mérések) switch views, gear icon opens the settings
  modal. Microphone input cannot be granted in the preview browser, so the tuner stays at
  "Mikrofon inaktív" — that is expected, not a defect.
